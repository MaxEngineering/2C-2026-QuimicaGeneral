## 🎯 Las dos cosas que hay que saber antes de empezar

### 1. La cátedra usa **Stock** y **Tradicional**

| Sistema                        | ¿Se usa?                                          | FeCl₃                      |
| ------------------------------ | ------------------------------------------------- | -------------------------- |
| Sistemático (prefijos griegos) | ❌ salvo nombres consagrados (dióxido de carbono) | tricloruro de hierro       |
| **Numerales de Stock**         | ✅                                                | cloruro de hierro**(III)** |
| **Tradicional**                | ✅                                                | cloruro férr**ico**        |

⚠️ **No se mezclan.** "Cloruro férrico" **o** "cloruro de hierro (III)". Nunca "cloruro férrico (III)" — eso se descuenta.

### 2. ⭐ En los ejercicios, Boggio te REGALA los números de oxidación

Miré las tres diapositivas de práctica de su clase (págs. 16, 23 y 24) y **las tres** empiezan igual:

> _"Datos: Ca: grupo 2 / Na: grupo 1 / **Pb: +2, +4** / **N: −3, +3, +5** / **S: −2, +2, +4, +6**"_
> _"Datos: **Cl: −1, +1, +3, +5, +7** / K: grupo 1 / Mg: grupo 2 / **Fe: +2, +3** / **Hg: +1, +2**"_

$$
\boxed{\text{Los nº de oxidación te los DAN. No hay que memorizarlos.}}
$$

**Esto cambia todo el plan de estudio.** Lo que tenés que tener automatizado no es una lista larga de compuestos, sino **el método**:

```
1. Clasificar el compuesto por el nombre  (¿-uro? ¿-ito/-ato? ¿"ácido"? ¿"hidruro"?)
2. Contar cuántos nº ox tiene el elemento  ← TE LO DAN EN LOS DATOS
3. Ubicar el sufijo en esa lista           (hipo-oso < oso < ico < per-ico)
4. Plantear  Σ(atomicidad × nº ox) = 0  y despejar
```

💡 **Traducción práctica:** para el parcial de nomenclatura **casi no hay que memorizar compuestos**. Hay que saber el **sistema de sufijos** y los **nombres propios** (que son los únicos que no salen por regla).

# 🧠 Lo que SÍ hay que memorizar (esto es todo)

No son compuestos: son **cuatro cosas**.

## 1. Los 10 iones poliatómicos (⭐ los 5 con estrella son los que salen de verdad)

| Ion         | Carga  | Nombre      |     | Ion       | Carga     | Nombre                      |
| ----------- | ------ | ----------- | --- | --------- | --------- | --------------------------- |
| ⭐**OH⁻**   | −1     | hidróxido   |     | **CO₃²⁻** | −2        | carbonato                   |
| ⭐**NO₃⁻**  | −1     | **nitrato** |     | **HCO₃⁻** | −1        | bicarbonato                 |
| ⭐**SO₄²⁻** | **−2** | **sulfato** |     | **PO₄³⁻** | **−3**    | fosfato                     |
| ⭐**NO₂⁻**  | −1     | nitr**ito** |     | **ClO⁻**  | −1        | hipoclorito                 |
| ⭐**SO₃²⁻** | −2     | sulf**ito** |     | **NH₄⁺**  | **+1** ⚠️ | **amonio** _(único catión)_ |

**Y ni siquiera hace falta memorizar las cargas:**

$$
\boxed{\text{carga} = -(\text{n}^\circ\ \text{de H que tenía el ácido})}
$$

HNO₃ (1 H) → NO₃⁻ · H₂SO₄ (2 H) → SO₄²⁻ · H₃PO₄ (3 H) → PO₄³⁻

## 2. El intercambio cruzado

> **La carga de uno baja como subíndice del otro. Cruzado, sin signo. Después simplificar.**

```
      K⁺  ╲    ╱  SO₄²⁻              Fe³⁺ ╲    ╱  NO₃⁻
            ╳                               ╳
      K₂  ╱    ╲  (SO₄)₁            Fe₁  ╱    ╲  (NO₃)₃

          → K₂SO₄                        → Fe(NO₃)₃
```

⚠️ **Paréntesis obligatorios** si el grupo lleva subíndice > 1: Fe(NO₃)₃, Ca(OH)₂ — nunca "CaOH₂".
⚠️ **Simplificar:** Ca²⁺ + O²⁻ → Ca₂O₂ → **CaO**.

## 3. El sistema de sufijos

| Cuántos nº ox tiene el elemento*(te lo dan)* | Los nombres, de menor a mayor                              |
| -------------------------------------------- | ---------------------------------------------------------- |
| **1**                                        | **nada** — "fluoruro de calcio", sin sufijo ni romano      |
| **2**                                        | ‑**oso** · ‑**ico**                                        |
| **3**                                        | **hipo**‑‑**oso** · ‑**oso** · ‑**ico**                    |
| **4**                                        | **hipo**‑‑**oso** · ‑**oso** · ‑**ico** · **per**‑‑**ico** |

$$
\boxed{\text{OSO chiquITO} \qquad \text{pICO de pATO}} \qquad \text{ácido -oso} \to \text{sal -ito} \;\;\cdot\;\; \text{ácido -ico} \to \text{sal -ato}
$$

$$
\boxed{\text{‑URO = SIN oxígeno} \qquad\qquad \text{‑ITO / ‑ATO = CON oxígeno}}
$$

⚠️ **El sufijo indica POSICIÓN, no un número fijo.** "‑ico" es +2 en el Cu y +5 en el I.

## 4. Los nombres propios (los únicos que no salen por regla)

**H₂O** agua · **NH₃** amoníaco · **PH₃** fosfina · **AsH₃** arsina · **SiH₄** silano · **CH₄** metano

⚠️ **NH₃ = amoníaco** (molécula) ≠ **NH₄⁺ = amonio** (catión +1). El NH₃ aparece en **dos** de las tres diapos de práctica.

# 🚨 Las 5 confusiones que cuestan puntos

| La confusión                    | La diferencia                                                                                             |
| ------------------------------- | --------------------------------------------------------------------------------------------------------- |
| **Sulfuro / sulfito / sulfato** | S²⁻ (**sin O**) · SO₃²⁻ (**+4**) · SO₄²⁻ (**+6**). Los tres empiezan igual                                |
| **Nitruro / nitrito / nitrato** | N³⁻ (**sin O**) · NO₂⁻ (**+3**) · NO₃⁻ (**+5**)                                                           |
| **Hidrácido vs hidruro**        | **Mirá de qué lado está el H.** HCl (adelante, +1, con **no metal**) vs KH (atrás, **−1**, con **metal**) |
| **NaCl vs NaClO**               | Sal de mesa vs**lavandina**. Clor**uro** (sin O) vs **hipo**clor**ito**                                   |
| **Mezclar Stock y Tradicional** | "Óxido plúmbico"**o** "óxido de plomo (IV)". Nunca los dos juntos                                         |

### El chequeo de 5 segundos antes de entregar

```
1. ¿Los nº de oxidación suman CERO?
2. ¿Puse paréntesis si el grupo lleva subíndice > 1?
3. ¿Se puede simplificar?              Ca₂O₂ → CaO
4. ¿El sufijo coincide con si hay o no oxígeno?
5. ¿Mezclé Stock con Tradicional?
```

## A1 · Los números de oxidación _(recordá: en los ejercicios te los DAN)_

**Los de un solo valor** — no llevan sufijo ni romano:

| **+1**        | **+2**         | **+3** | **−1**            | **−2**   | **+1**   |
| ------------- | -------------- | ------ | ----------------- | -------- | -------- |
| Li, Na, K, Ag | Mg, Ca, Ba, Zn | Al     | **F** _(siempre)_ | **O** ⚠️ | **H** ⚠️ |

⚠️ **O = −2** salvo en **peróxidos** (−1) · **H = +1** salvo en **hidruros metálicos** (−1).

**Los de varios valores:**

| Elemento   | Nº ox             |     | Elemento  | Nº ox                 |
| ---------- | ----------------- | --- | --------- | --------------------- |
| Cu         | +1, +2            |     | Cl, Br, I | −1,**+1, +3, +5, +7** |
| Fe, Co, Ni | +2, +3            |     | S         | −2, +4, +6            |
| Hg         | +1, +2            |     | N         | −3, +3, +5            |
| Pb, Sn     | +2, +4            |     | C         | −4, +2, +4            |
| Mn         | +2, +4, +6,**+7** |     | P         | −3, +3, +5            |

💡 Los halógenos son **impares de dos en dos**: +1, +3, +5, +7 (más el −1 de la sal).

$$
\boxed{\sum(\text{atomicidad}\times\text{n}^\circ\text{ox}) = 0 \quad \text{(o la carga, si es un ion)}}
$$

## A3 · Las 3 series que conviene poder reconstruir solo

$$
\text{Óxido} \xrightarrow{+\,\text{H}_2\text{O}} \text{Oxoácido} \xrightarrow{\text{H}\,\to\,\text{Metal}} \text{Oxosal}
$$
